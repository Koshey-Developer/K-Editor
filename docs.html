Обзор

K-Editor — это WYSIWYG-редактор на основе contentEditable. Цветовая схема — тёмный оливковый + золото.

Редактор работает полностью автономно — все стили, скрипты и иконки локально, без внешних зависимостей. PHP-часть нужна только для сохранения документов на сервере.

PHP-файлы (серверная часть)

PHP-файлы нужны только для работы на сервере с поддержкой PHP 7.4+ и модулем pdo_mysql. Без сервера редактор работает автономно — сохраняет в localStorage браузера.

api/save.php

REST API для работы с документами. Поддерживает три метода:

МетодПараметрыОписание
POST { content, title, id? } Сохранить документ. Если id указан — обновить существующий.
GET ?id=N (опционально) Получить документ по ID или список всех документов.
DELETE { id } Удалить документ по ID.

demo/index.php

Страница демонстрации. Загружает документы из MySQL и отображает их в красивом формате:

  • Сайдбар со списком всех документов
  • Основная область с рендерингом HTML-контента
  • Стили в том же стиле что и редактор (тёмный оливковый + золото)
  • Ссылка на редактор для создания новых документов

MySQL база данных

База keditor, таблица documents. Создаётся автоматически. Структура:

CREATE TABLE documents ( id INT AUTO_INCREMENT PRIMARY KEY, title VARCHAR(255) DEFAULT 'Без названия', content LONGTEXT NOT NULL, created_at DATETIME DEFAULT CURRENT_TIMESTAMP, updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4

Как использовать

Без сервера (локально)

Просто откройте index.html в браузере. Всё работает — форматирование, загрузка файлов, предпросмотр. Контент сохраняется в localStorage.

С сервером (PHP + MySQL)

  1. Скопируйте папку keditor на сервер с PHP 7.4+ и MySQL
  2. Убедитесь что модуль pdo_mysql включён в php.ini
  3. Создайте базу данных keditor или используйте существующую (таблица создаётся автоматически)
  4. Отредактируйте данные подключения в api/save.php и demo/index.php (хост, пользователь, пароль, имя базы)
  5. Откройте index.html — при нажатии «Сохранить» данные отправятся на сервер
  6. Откройте demo/index.php — увидите сохранённые документы

Встроить в свой проект

<!-- Подключить стили --> <link rel="stylesheet" href="keditor/css/editor.css"> <link rel="stylesheet" href="keditor/css/icons.css"> <!-- Вставить HTML редактора --> <div class="editor-container"> <div class="toolbar">...</div> <div id="editor" contenteditable="true"></div> </div> <!-- Подключить JS --> <script src="keditor/js/editor.js"></script> <!-- Получить HTML --> <script> const content = window.kEditor.editor.innerHTML; </script>
